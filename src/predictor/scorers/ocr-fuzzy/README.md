# ocr-fuzzy

Модуль — ограниченный fallback для длинных кириллических терминов, повреждённых
OCR или разрывами PDF-токенов.

## Как работает

- сравнивает только достаточно длинные кириллические токены;
- использует нормированное edit-distance сходство;
- умеет склеивать несколько соседних OCR-фрагментов;
- требует совпадение фокуса вопроса в том же коротком предложении;
- отключается, если несколько вариантов ответа имеют слишком похожие длинные
  токены.

Модуль не применяет нечёткий поиск к коротким словам. Evidence возвращается как
`cyrillic_ocr_segment`.

## Публичный API

- `cyrillicOcrTokenSimilarity(left, right)`;
- `cyrillicOcrCoverage(answerText, sourceText)`;
- `bestCyrillicOcrSupport(...)`.
