# multi-set

Модуль декодирует полный набор ответов из явно записанного диапазона или
перечисления порядковых значений.

Пример структуры источника: `пациентам с 1–3 степенью рекомендуется ...`.
Если варианты ответа соответствуют степеням 1, 2, 3 и 4, модуль выбирает точный
набор первых трёх.

## Защитные условия

- работает только для `multi`;
- требует атомарную строку с целевым действием и условиями вопроса;
- не принимает диапазоны ссылок за значения;
- не объединяет разные пункты;
- воздерживается при конфликтующих одинаково релевантных строках.

## Публичный API

- `resolveExplicitOrdinalRangeSet(...)`;
- `applyExplicitOrdinalRangeSetScores(...)`.

Результат использует evidence `explicit_ordinal_range_set`.
