# definition

Модуль обрабатывает определения, завершение формулировок, частотную полярность
и полярность рекомендаций.

## Возможности

- ищет связку `термин — определение` в локальном фрагменте;
- сопоставляет точное продолжение вопроса-определения;
- выделяет словесную частоту (`всегда`, `редко`, `не характерно`);
- связывает короткую метку с её определением;
- штрафует несовместимые отрицания и чрезмерно абсолютные формулировки;
- различает положительную и отрицательную рекомендацию.

Модуль возвращает как evidence, так и adjustments. Его правила основаны на
структуре текста и не содержат ответов из датасета.

## Публичный API

Публичные функции `best*Support` ищут evidence, функции `*Adjustment`
возвращают поправку score, а `frequencyPolarity` и
`questionDefinitionLabel` извлекают признаки формулировки.
