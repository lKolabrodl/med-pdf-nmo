# age-stage

Модуль обрабатывает ответы, в которых важны возрастная форма заболевания,
римская стадия или номер строки классификации.

## Как работает

- сопоставляет возрастные формы (`детская`, `взрослая` и похожие формы слов)
  с локальным фрагментом PDF;
- приводит арабские и римские номера стадий к совместимым вариантам;
- связывает компактную метку ответа со строкой таблицы или списка;
- использует `ordinal-row-gate`, чтобы не принять номер условия за метку ответа.

Основные evidence-kind: `age_form_segment`, `roman_stage_segment` и
`answer_ordinal_row`. Scorer применяется только к `single`-вопросам и
воздерживается от ответа, если номер или возрастная форма неоднозначны.

## Публичный API

- `bestAgeFormSupport(...)`;
- `bestRomanStageSupport(...)`;
- `bestAnswerOrdinalRowSupport(...)`.
