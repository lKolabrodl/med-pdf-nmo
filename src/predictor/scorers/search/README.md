# search

Модуль содержит базовый структурно-лексический поиск по тексту PDF.

## Возможности

- фразы ответа рядом с вопросом;
- сегменты после явного question-anchor;
- списки внутри найденной секции;
- подписи строк и их значения;
- предшествующая короткая метка вопроса.

`find*Segments` один раз строят ограниченные области, а `best*Support`
оценивают конкретный вариант ответа внутри этих областей. Широкие совпадения
имеют меньшую надёжность, чем табличные или tuple-resolver evidence.

Основные kind: `question_answer_phrase`, `answer_window`,
`preceding_question_label`, `question_anchor_segment`,
`section_list_segment` и `row_label_segment`.

## Публичный API

Экспортируются функции поиска сегментов и соответствующие
`best*Support`-функции.
