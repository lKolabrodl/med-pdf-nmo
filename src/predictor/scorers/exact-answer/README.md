# exact-answer

Модуль ищет длинный вариант ответа как точную фразу в PDF.

Он предназначен для насыщенных числами назначений, где потеря одного значения
меняет смысл: например, сочетание разовой дозы, кратности и длительности курса.

## Защитные условия

- используется только в `single`-режиме;
- включается для вопросов о назначении внутрь;
- требует не менее трёх числовых значений в ответе;
- проверяет полное числовое покрытие фразы;
- требует близость к фокусу вопроса или к релевантной странице.

Успешный поиск возвращает evidence `exact_answer_phrase`, иначе `null`.

## Публичный API

- `bestExactAnswerSupport(...)`.
