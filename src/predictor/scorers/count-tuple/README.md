# count-tuple

Модуль связывает уникальное количество с объектом счёта внутри одного
ограниченного фрагмента.

Например, для вопроса о количестве этапов он выбирает число только из клаузы,
где одновременно упомянуты этапы и нужный предмет, а не соседнее число.

## Ограничения

- работает только для `single`-вопросов;
- требует семейство коротких числовых вариантов ответа;
- принимает как цифры, так и числительные;
- воздерживается, если в одной подходящей клаузе найдено несколько кандидатов;
- не объединяет значения из разных предложений.

## Публичный API

- `resolveClauseLocalCountTuple(...)` — строит структурное разрешение;
- `applyClauseLocalCountTupleResolver(...)` — применяет его к массиву score.

Успешное совпадение создаёт evidence `clause_count_tuple_segment`.
