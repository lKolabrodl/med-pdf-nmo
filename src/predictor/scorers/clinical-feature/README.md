# clinical-feature

Модуль проверяет варианты ответа для multi-вопросов о клинических признаках
заболевания.

## Как работает

1. Включается только для положительного вопроса с явными словами
   `клинические признаки`.
2. Выделяет специфичные токены заболевания и ответа.
3. Ищет их в одном предложении или в ближайших следующих предложениях.
4. Различает положительное упоминание и явно отрицанный признак.

Положительное совпадение возвращается как `clinical_feature_segment`.
Если признак в источнике отрицается, модуль возвращает штраф с evidence
`clinical_feature_negated`.

## Публичный API

- `clinicalFeatureAdjustment(context)` — возвращает support, adjustment и
  диагностическое evidence.
