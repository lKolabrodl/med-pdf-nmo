# abbreviation-alias

Модуль связывает вариант ответа с сокращением, определённым внутри самого PDF.
Например, если в разделе сокращений есть пара `АБС — альфа-бета состояние`,
scorer может искать `АБС` в содержательном фрагменте вместо полной расшифровки.

## Как работает

1. Берёт пары `сокращение → расшифровка` из `pdfText.abbreviations`.
2. Проверяет, что текст ответа достаточно полно совпадает с расшифровкой.
3. Ищет сокращение вне страницы словаря и только рядом с фокусом вопроса.
4. Возвращает лучшее evidence `abbreviation_alias_window`.

Модуль работает только в режиме `multi` и не использует список сокращений как
самостоятельное доказательство: в основном тексте PDF обязательно должно быть
найдено употребление сокращения.

## Публичный API

- `bestAbbreviationAliasSupport(context)` — возвращает лучшее evidence или `null`.
