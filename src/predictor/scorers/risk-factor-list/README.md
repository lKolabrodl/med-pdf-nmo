# risk-factor-list

Модуль извлекает точный набор факторов риска из направленного списка.

## Как работает

- находит заголовок вида `факторами риска развития X являются`;
- при необходимости раскрывает сокращение `X` из словаря текущего PDF;
- ограничивает список следующим заголовком или структурной границей;
- сопоставляет варианты только с дочерними пунктами;
- не принимает обратную связь `X является фактором риска Y` за фактор риска X.

Модуль работает в `multi`-режиме и возвращает
`risk_factor_list_member` для каждого подтверждённого варианта.

## Публичный API

- `resolveRiskFactorList(...)` — `Map` структурных разрешений по id ответа.
