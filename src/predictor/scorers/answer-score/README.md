# answer-score

Модуль — центральный агрегатор evidence для одного варианта ответа.
Он вызывает специализированные scorer-модули, применяет их веса и собирает
единый сырой score вместе со списком объясняющих фрагментов.

## Как работает

1. Получает общий `AnswerScoringContext`.
2. Запускает лексические, структурные, числовые и клинические scorer-ы.
3. Складывает положительные evidence и штрафные adjustments с заданными весами.
4. Применяет guards для плотных семейств вариантов.
5. Сортирует evidence по убыванию score.

Модуль не выбирает финальный вариант и не вычисляет confidence. Эти этапы
выполняются последующими слоями predictor.

## Публичный API

- `scoreAnswer(context)` — возвращает `{raw, evidence}` для одного ответа.
