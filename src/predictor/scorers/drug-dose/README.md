# drug-dose

Модуль ищет назначение конкретного препарата с дозой, единицей измерения,
кратностью и, при наличии, способом введения.

## Как работает

Scorer выделяет из вопроса и ответа лекарственный субъект, числовые значения и
единицы. Затем он проверяет их совместное присутствие в одной строке или
небольшом окне. Для составных назначений учитывается порядок компонентов, чтобы
доза соседнего препарата не была присвоена выбранному ответу.

Модуль работает только для `single`-вопросов и возвращает
`drug_dose_segment`. При неполном или неоднозначном связывании возвращается
`null`.

## Публичный API

- `bestDrugDoseSupport(...)`.
