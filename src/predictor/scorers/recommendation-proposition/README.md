# recommendation-proposition

Модуль представляет рекомендацию как атомарную пропозицию: действие, адресат,
полярность, ограничение и универсальный квантор.

## Как работает

1. Выделяет из вопроса целевые токены действия.
2. Разбирает строки рекомендаций и варианты ответа в одинаковые признаки.
3. Сравнивает положительную/отрицательную полярность и ограничения вроде
   `только` или `всем`.
4. Возвращает структурное разрешение только при уникальном совместимом
   варианте.

Модуль работает для `single` и воздерживается, если различие между вариантами
нельзя надёжно связать с одной пропозицией. Evidence-kind:
`recommendation_proposition`.

## Публичный API

- `recommendationTargetTokens(question)`;
- `recommendationPropositionFeatures(text, contraindicationQuestion, isAnswer)`;
- `resolveRecommendationProposition(...)`.
