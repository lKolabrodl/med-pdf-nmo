# classification

Модуль разбирает вопросы о классификациях: цифровые метки, коды МКБ,
исключения из класса и визуальные колонки таблиц.

## Как работает

- связывает название показателя с ближайшим номером;
- ищет точные коды классификации с учётом границ токена;
- различает включённые и исключённые из класса состояния;
- восстанавливает целевую колонку по координатам PDF;
- поддерживает короткие подписи строк, если они подтверждены табличным
  контекстом.

Модуль возвращает структурные evidence и может добавить отрицательный
adjustment при явном противоречии. Среди evidence-kind:
`classification_code_segment`, `mkb_class_exclusion_absent`,
`visual_table_column`, `exact_short_label_visual_row` и
`short_label_visual_row`.

## Публичный API

Публичные функции строят табличные цели, проверяют применимость визуальной
таблицы и ищут поддержку конкретного ответа.
