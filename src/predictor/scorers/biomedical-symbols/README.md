# biomedical-symbols

Модуль ищет латинские медицинские обозначения, коды и символы генов, включая
частые OCR-подмены кириллицы, латиницы и цифр.

## Как работает

- извлекает буквенно-цифровые токены из ответа;
- строит ограниченный набор типографских и OCR-вариантов;
- сравнивает их с токенами релевантных страниц;
- для вопросов о мутациях ищет код гена в том же предложении, что и фокус
  вопроса.

Модуль не содержит справочника медицинских фактов. Все варианты строятся только
из формы символов. Основные evidence-kind: `latin_fuzzy_ocr` и
`gene_sentence_segment`.

## Публичный API

- `latinAnswerTokens(text)`;
- `bestLatinFuzzySupport(...)`;
- `geneMutationQuestion(question)`;
- `sentenceSegments(text)`;
- `bestGeneSentenceSupport(...)`.
