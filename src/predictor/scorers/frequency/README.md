# frequency

Модуль распознаёт варианты с периодичностью или длительностью и ищет их в
строке рекомендации.

## Как работает

- определяет наличие числа и единицы времени;
- строит допустимые словоформы для лет, месяцев, недель, дней и часов;
- требует рекомендационный контекст;
- проверяет, что найденная частота относится к предмету ответа, а не к соседнему
  препарату или процедуре;
- ограничивает поиск релевантными страницами и фокусом вопроса.

Успешное совпадение возвращает `frequency_recommendation_line`.

## Публичный API

- `frequencyAnswer(answerText)` — проверка формы ответа;
- `frequencySearchPhrases(answerText)` — поисковые варианты;
- `bestFrequencyRecommendationSupport(...)` — поиск evidence.
