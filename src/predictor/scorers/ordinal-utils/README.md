# ordinal-utils

Модуль содержит общие функции нормализации порядковых значений.

## Возможности

- преобразует арабские и римские обозначения от I до X в число;
- строит взаимозаменяемые арабские и римские варианты стадии;
- использует общую поисковую нормализацию проекта.

Модуль не анализирует вопрос и не создаёт evidence. Его используют scorer-ы
списков, стадий и классификаций.

## Публичный API

- `ordinalValueToNumber(value)` — число или `null`;
- `romanStageVariants(stage)` — нормализованный набор вариантов записи.
