# recommendation-set

Модуль восстанавливает точный multi-answer набор из нескольких повторяющихся
рекомендаций с общим контекстом пациента.

## Как работает

- строит атомарные recommendation-сегменты;
- требует один и тот же адресат или условие вопроса;
- сопоставляет каждый пункт с одним вариантом;
- исключает отрицательные или относящиеся к другой группе рекомендации;
- возвращает набор только при достаточном контрасте и однозначности.

Каждый выбранный вариант получает evidence
`repeated_recommendation_target`. Модуль не объединяет совпадения с разных
несвязанных разделов.

## Публичный API

- `resolveRepeatedRecommendationSet(...)` — `Map` разрешений по id ответа.
