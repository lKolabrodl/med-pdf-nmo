# fibrosis-stage

Модуль сопоставляет стадию фиброза с её словесным описанием в строке шкалы.
Поддерживаются обозначения `F0`–`F4`, арабские номера и общие описательные
категории вроде отсутствующего, умеренного или выраженного фиброза.

## Как работает

Scorer определяет, что именно задано в вопросе — номер стадии или описание, —
и извлекает вторую часть из варианта ответа. Затем он ищет строку PDF, где
номер и описание встречаются вместе.

Модуль работает только в `single`-режиме. Он не добавляет медицинские знания:
соответствие должно быть явно записано в PDF. Результат имеет kind
`fibrosis_stage_row`.

## Публичный API

- `bestFibrosisStageSupport(...)`.
