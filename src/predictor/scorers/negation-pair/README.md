# negation-pair

Модуль разрешает пару вариантов, которые отличаются только явным отрицанием.

## Как работает

1. Находит ровно одну пару ответов с общей лексической основой.
2. Выделяет из вопроса предмет и условие.
3. Ищет одну ограниченную клаузу, где утверждение или отрицание относится к
   этому предмету.
4. Выбирает полярно совместимый вариант и не переносит отрицание между
   соседними предложениями.

Модуль работает только для `single`-вопросов и воздерживается при
неоднозначности. Успешное разрешение создаёт evidence
`negation_pair_clause`.

## Публичный API

- `resolveNegationPairClause(...)`;
- `applyNegationPairClauseResolver(...)`.
