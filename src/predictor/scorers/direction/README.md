# direction

Модуль проверяет направленность утверждения: отрицание, время, клиническое
течение, контраст и исключённые условия.

## Как работает

- сравнивает полярность вопроса, ответа и найденного evidence;
- различает временные маркеры `до`, `после`, `ранее`, `в дальнейшем`;
- проверяет признаки улучшения, ухудшения и стабильного течения;
- штрафует перенос модификатора на другой объект;
- обнаруживает несовпадение после конструкций `в отличие от`;
- не позволяет использовать факт, относящийся к исключённому условию.

Функции возвращают support и/или adjustment. Модуль не ищет основной факт
самостоятельно, а уточняет направление уже найденного контекста.

## Публичный API

- `polarityAdjustment(...)`;
- `temporalCueAdjustment(...)`;
- `clinicalCourseCueAdjustment(...)`;
- `contrastCueMismatchAdjustment(...)`;
- `excludedConditionMismatchAdjustment(...)`.
