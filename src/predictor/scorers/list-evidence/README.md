# list-evidence

Модуль извлекает доказательства из ограниченных списков, порядковых строк и
секций показаний.

## Возможности

- находит список, привязанный к заголовку или вопросу;
- отличает элементы внутри целевой секции от совпадений за её границами;
- сопоставляет номер типа, стадии или степени с текстом строки;
- связывает вариант с меткой показания;
- проверяет область действия соседних показаний;
- учитывает явные возрастные противопоказания.

Модуль возвращает как положительные evidence, так и локальные штрафы.
Основные kind: `bounded_list_segment`, `ordinal_list_segment`,
`type_ordinal_segment`, `indication_label_segment` и
`age_eligibility_contraindication`.

## Публичный API

Функции `findBoundedListSegments` строят сегменты, `best*Support` ищут evidence,
а `*Adjustment` возвращают поправку score.
