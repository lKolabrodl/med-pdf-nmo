# hierarchical-list

Модуль восстанавливает двухуровневые списки с римскими родительскими пунктами и
нумерованными дочерними элементами.

## Как работает

1. Объединяет последовательные строки и переносы между страницами.
2. Строит кластеры соседних родителей.
3. По формулировке вопроса выбирает один родительский пункт.
4. Поддерживает только ответы из его дочернего списка и штрафует элементы
   контрастных ветвей.

Модуль работает в `multi`-режиме и требует как минимум два сопоставимых
родительских пункта. Это защищает от интерпретации случайного одиночного списка
как иерархии. Evidence имеет kind `hierarchical_list_member`.

## Публичный API

- `buildHierarchicalListClusters(pages)`;
- `resolveHierarchicalList(...)`.
