# ordinal-row-gate

Модуль проверяет, можно ли считать порядковое значение в ответе меткой
классификационной строки.

Он принимает формы вроде `2 стадия`, `стадия II` или `тип III`, но отклоняет
номер, который встречается только как условие внутри длинного ответа. Также
gate запрещает применять row-mapper к вопросам `сколько типов/стадий`.

Это защитный модуль: он не возвращает evidence и не начисляет score.

## Публичный API

- `answerOrdinalRowApplicable({question, answerText, label})` — возвращает
  `true`, только если номер стоит в позиции прямой метки ответа.
