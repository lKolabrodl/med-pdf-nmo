# sibling-list

Модуль связывает ответы с соседними пунктами одного списка или строками одной
классификации.

## Режимы

- в `multi` выбирает элементы внутри блока, названного в вопросе;
- в `single` может по описанию строки восстановить её короткую метку;
- поддерживает нумерованные, римские и качественные подписи;
- разворачивает явные ссылки вида `тип IV = тип III + дополнительный признак`.

Scorer требует sibling-контраст: одиночный bullet не считается достаточной
структурой. Это предотвращает захват случайного списка. Основные evidence-kind:
`sibling_list_member`, `sibling_list_label` и `sibling_list_body`.

## Публичный API

- `buildSiblingListBlocks(pages)`;
- `resolveSiblingList(...)`.
