# tie-break

Модуль разрывает точную ничью raw score между вариантами одиночного вопроса,
используя со-встречаемость значения варианта со специфичными токенами условия из
самого PDF.

## Как работает

1. Срабатывает только в `single`-режиме и только при ТОЧНОЙ ничьей верхнего raw
   score между двумя и более короткими/числовыми вариантами (dose/threshold/
   generation семейство).
2. Строит редкость токенов вопроса по числу страниц, где они встречаются, и
   оставляет только специфичные (не общие) токены условия.
3. Для каждого связанного варианта ищет в топ-страницах вопроса физическую
   строку, где значение варианта стоит рядом с этими специфичными токенами.
4. Если есть строго доминирующий по со-встречаемости вариант, его raw слегка
   повышается, чтобы селектор выбрал его; иначе выбор не меняется.

Модуль не читает метки, id, ожидаемое число ответов или медицинские факты — он
опирается только на со-встречаемость токенов в тексте документа. Управляется
флагом `numericTieConditionBreak`.

## Публичный API

- `applyNumericTieConditionBreak(...)`.
